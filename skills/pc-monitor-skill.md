# PC Monitor Awareness

Use this when sir asks:

- what am I doing right now?
- what was I working on?
- which app am I using?
- what is running on my PC?
- how is my system doing?
- what changed recently?

Awareness includes recent active windows, top apps/processes, memory use, battery, and recent PC activity.

Behavior:

- Answer naturally from observed activity.
- Do not overstate certainty.
- If activity is sparse, say what is visible and what is not.
- Keep the answer concise.
- Do not expose raw logs, storage details, scores, or monitor internals unless sir asks for debugging details.
