# bug-repro

Reproduce a reported bug with a minimal script before fixing it. Use when given a bug report, a failing behavior, or "it doesn't work".

Intended access: files, shell. These declarations are advisory; existing tool approvals apply.

Read SKILL.md for the complete workflow. Validate with node scripts/check-skills.mjs from the checkout root. The golden fixture pins the real returned instructions, not a model answer.
