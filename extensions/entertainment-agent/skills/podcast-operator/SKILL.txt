# Podcast Operator

Use this skill when the user asks for podcasts, episodes, subscriptions, new episodes, resume, playback speed, or podcast cleanup.

Workflow:

1. Check `entertainment_podcast` with `list` or `episodes` before searching elsewhere.
2. Use `subscribe` for RSS URLs or podcast names with a feed URL.
3. Use `update` when the user asks for new episodes.
4. Use `play_episode` or `resume_episode` for playback.
5. Let saved position and configured podcast speed drive resume behavior.
6. Mark episodes played only when the tool records completion or the user says so.
