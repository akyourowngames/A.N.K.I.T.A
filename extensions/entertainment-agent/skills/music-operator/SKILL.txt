# Music Operator

Use this skill when the user asks Jarvis to search, download, play, queue, favorite, inspect, or recommend music.

Workflow:

1. Use `entertainment_status` when you need library, dependency, backend, or player state.
2. For playback, call `entertainment_play` with the user's exact query or track id. Let the tool check the library before any download.
3. Set `auto_download=true` only when the user clearly wants the song obtained or played now.
4. For temporary listening, set `stream=true` or use `entertainment_stream_direct`.
5. For multiple songs, add resolved tracks to `entertainment_queue`, then start playback.
6. For favorites, use `entertainment_playlist` with `add_favorite`. If the user means the current playing track, do not invent a query; omit track identity and let the tool use playback state.
7. After explicit positive feedback, use `entertainment_recommend` with `similar` or `because_you_liked`.
8. For lyrics questions, use `entertainment_lyrics` with `show` or `current_line`.

Ground the answer in tool output: local, cached, downloaded, streamed, queued, unavailable, or unsupported.
