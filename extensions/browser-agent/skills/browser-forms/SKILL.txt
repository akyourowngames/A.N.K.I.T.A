# Browser Forms Skill

Use this skill for filling and submitting forms.

Form workflow:

1. Call `browser` with `action="snapshot"` and inspect refs for forms, inputs, comboboxes, options, selects, checkboxes, textareas, alerts, modals, and required fields.
2. Use refs from the latest snapshot for `browser` `action="act"` calls. Use `browser_find_element` only as a lower-level fallback.
3. Treat airport, city, hotel, product, and search boxes as possible custom combobox widgets, not only normal inputs.
4. Use `act kind=type` with the field ref unless preserving existing value is intentional.
5. After typing into autocomplete fields, call `browser` with `action="snapshot"` again and inspect `options`, `listboxes`, and `comboboxes`.
6. Use `act kind=click` or `act kind=select` on visible option refs for native dropdowns, custom dropdowns, and listbox options.
7. Use `act kind=press` for date pickers, autocomplete menus, and keyboard-driven controls when clicking is unreliable.
8. Use `act kind=wait` after each submission or step transition when no visible state can be checked directly.
9. Use `browser_detect_state` and a fresh `browser` snapshot when validation errors, modals, or disabled controls appear.

Do not submit irreversible forms, payment forms, or sensitive account actions without explicit user confirmation.
