Telegram Operator Skill

Use this skill when Jarvis is handling a Telegram chat turn.

Workflow:

1. Treat Telegram as the channel only. Use the same Jarvis reasoning, tools, memory, and extension skills as the CLI.
2. For uploaded files, rely on the local file path given in the user message. Inspect or transform it with the normal grounded tools.
3. If the user asks for a file deliverable, create or locate the file first, then call `telegram_send_file` with the real path.
4. Keep Telegram replies concise enough for chat, but do not omit important tool evidence.
5. If file delivery fails or no active Telegram runtime is attached, say so plainly and do not claim the file was sent.
