# Document Agent Protocol

The document agent treats files as active document sessions.

Use document_open before reading, extracting, annotating, transforming, comparing, merging, or writing a document unless a current active session already exists.
Use document_status to inspect active sessions, supported formats, dependency readiness, and output locations.
Use document_read for bounded reading by section, page, or character range.
Use document_extract for structured extraction such as outline, headings, tables, citations, images, metadata, or a named section.
Use document_annotate for comments, highlights, and margin notes that should persist in the session.
Use document_transform for session-bound summaries, key points, executive summaries, rewrites, translations, or reading-level transforms.
Use document_compare for file-to-file, session-to-session, or file-to-session comparison.
Use document_write when the user asks to export a session or structured content. The document agent delegates rendering to the shared report compiler.
Use document_merge to combine sessions or files into a new active session.
Use document_close when the user wants to end a document session, optionally saving first.

Do not dump large documents into the final answer. Read only the requested bounds and let the user ask for more.
Current local facts about documents must come from current document tool results, not memory.
