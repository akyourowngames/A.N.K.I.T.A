# Report Compiler Protocol

The report compiler is the shared rendering layer for Jarvis agents.

Use compiler_validate when a user provides structured report content and wants to know whether it is renderable.
Use compiler_preview when the user wants to see a report in chat before writing a file.
Use compiler_render when the request already includes structured content, or another tool result includes compiler_content in the compiler schema.

Do not invent missing content. If the user asks research or document tools to produce a report, prefer the agent tool that owns the evidence/session and let that tool pass structured content to the compiler.
Keep final answers based on compiler result fields: output path, format, template, warnings, and dependency errors.
