# Desktop blank startup — 2.5.2

## Reproduction and cause

The complete main renderer from 2.5.1 fails before React mounts. With the shipped
index HTML and its actual Content Security Policy, the live trace reports:

```text
DESKTOP_FULL_APP_REPRO {"visible":false,"rootChildren":0}
EvalError: Evaluating a string as JavaScript violates ... script-src 'self'
at Function (<anonymous>)
at tools/browser/refs.mjs:120:35
```

`BrowserStage` loads shared progress metadata, which loads operation policy.
Operation policy previously imported the form-field limit from `refs.mjs`.
That ref module also constructs the host-side batch DOM inspection function with
`Function(...)` at module initialization. Loading it into the renderer violates
the deliberate prohibition on `unsafe-eval`. The same eager call appeared in the
built main bundle, explaining both dev and packaged blank startup.

The earlier isolated ChatPane check served custom HTML without the production
CSP and therefore missed this failure. The island entry point did not reproduce
the main renderer's import failure.

## Correction

`MAX_BROWSER_FORM_FIELDS` now belongs to the pure operation-policy module.
The ref module imports and re-exports the same constant, retaining its existing
API and the single form limit. Host probes stay in the browser backend. No CSP
relaxation, browser removal, ref rewrite, credential change or dependency upgrade
is part of this fix.

## Publication boundary

The Windows installer, portable executable, blockmap and update manifest are
rebuilt from this checked source. Manual publication retains the user's earlier
instruction to stop investigating the separate Chrome runner failures. No
exact-commit remote CI success is claimed; the existing workflow still requires
its tests. The new full local suite passes, while the old Chrome CI
navigation/cart failure remains explicitly documented in 2.5.1 and 2.5.2 notes.

The release tag must point at the checked source commit. Public-asset checks
compare downloaded bytes against the locally built files, GitHub SHA-256 digests,
installer size/SHA-512 in `latest.yml`, and the exact changelog notes. Generated
EXEs, diagnostics and local assistant settings are excluded from Git source.
