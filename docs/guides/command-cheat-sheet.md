# Terminal and desktop cheat sheet

Run `node chat.mjs commands` for the current complete table, or
`node chat.mjs commands skills` to search it. Redirect the output to a Markdown
file to share it. It runs offline before login and reads the same registry used by
terminal help plus the real desktop command palette, including installed skills.

Desktop actions include the exact Ctrl+K search term. Terminal-only commands and
desktop-only actions are labelled explicitly; scheduled tasks are not confused
with terminal command processes. New flags, commands and palette contributions
appear from their metadata without maintaining a copied reference table.

Verification covers every registered command and flag, actual palette actions,
search, contributed table characters and a real CLI round trip with an invalid
provider configured (proving no provider bootstrap is required).
